# Curriculum link copy runtime verification

The first curriculum track link button was activated in the browser preview. Its accessible hint changed from `섹션 링크 복사` to `섹션 링크가 복사되었습니다`, and its visible label changed from `LINK` to `COPIED` with the yellow copied-state treatment. The same runtime view exposes four total copy controls: three curriculum tracks and the curriculum output/process section. The controls remain positioned at the upper-right of their sections after scrolling.
