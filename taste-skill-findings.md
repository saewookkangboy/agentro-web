# taste-skill findings

Source: https://github.com/Leonxlnx/taste-skill

The repository positions itself as an anti-slop frontend framework focused on stronger layout, typography, motion, and spacing rather than generic boilerplate. The current repository structure includes a dedicated redesign skill with audit checks across typography, color, layout, interactivity, content, components, iconography, and code quality.

Key principles to apply to Agentro:

1. Establish a clear design-system map before polishing individual screens: color roles, shape language, typography, spacing rhythm, motion, density, and variance.
2. Avoid generic centered hero compositions, excessive pills, decorative dots, section-number eyebrows, and repetitive card grids. Use intentional composition and varied layout density.
3. Use typography as the primary hierarchy: controlled display scale, readable body measure, deliberate line height, and consistent vertical rhythm.
4. Keep color, shape, and theme consistent across light/dark modes. Treat dark surfaces as a deliberate palette, not a simple inversion.
5. Align CTAs consistently within card groups and audit optical rather than only mathematical centering.
6. Use motion with purpose: scroll reveals, hover feedback, and transitions should be brief, coherent, and respect reduced-motion preferences.
7. Improve flat sections with meaningful background treatment or evidence rather than filler decoration.
8. Audit mobile layouts, loading/empty states, component semantics, and keyboard/focus behavior as part of visual quality.

The README also notes a v1.5 redesign skill with a prioritized fix order, dark mode protocol, design variance guidance, hero discipline, bento/card rules, and a complete pre-flight check. These principles will guide the refinement rather than copying the repository's visual assets or code.
